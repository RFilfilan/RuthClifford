My writings

## Deployment

The site is deployed to GitHub Pages by the workflow in `.github/workflows/deploy.yml`
whenever a commit is pushed to `main`. To enable the first deployment, set the
repository's **Settings → Pages → Build and deployment → Source** to **GitHub Actions**.
You can also start a deployment manually from the Actions tab.

The Astro build is configured for the project URL
`https://rfilfilan.github.io/RuthClifford/`.
